# Palisade Interviews

This repository collects transcripts of interviews published by **Palisade Research** on its [YouTube channel](https://www.youtube.com/@PalisadeResearch). The interviews are Palisade Research’s work; this repository provides formatted transcripts and editorial navigation for reading, analysis, and quotation.

## Original interviews

- [Palisade Research on YouTube](https://www.youtube.com/@PalisadeResearch)
- [Browse the channel’s videos](https://www.youtube.com/@PalisadeResearch/videos)

Video links were matched by interviewee and description using the [LLM Bento Palisade Research directory](https://www.llm-bento.com/channels/palisade-research). Use the original videos to check quotations and context; the transcripts have not been verified against the audio.

## Editorial criteria

- Subtitles were joined into paragraphs without summarizing, translating, or reordering the interview content. Questions are those appearing in the interviews, not questions added by the editors.
- Words, figures, repetitions, openings, and closings were preserved. Only the proper names documented at the end of each timestamped version were normalized.
- The text-only versions omit the nonverbal cues `[music]`, `[snorts]`, `[sighs]`, `[clears throat]`, and `[laughter]`. Censored-word markers and all figures mentioned in the speech were retained.
- The original source files and earlier transcript versions are not included in this repository. The source for Phuong was received as a Markdown file; the other sources were TXT files.
- The original editorial review recorded that the eight later transcripts preserved the source content except for documented name changes, and that all twelve text-only versions matched their formatted counterparts except for nonverbal cues.
- The README, thematic headings, and editorial notes have been translated into English. The English interview text is unchanged.

## Before quoting or publishing

The received files did not include individual video links or publication dates. Video links were added later from the directory cited above; publication dates remain unverified. The transcripts have not been checked against the audio, and the interviewees’ claims have not been verified. The notes flag some apparent recognition errors, but are not exhaustive.

The names Jeremy Schlatter, Eli Tyre, and Palisade Research were previously checked against the [official team page](https://palisaderesearch.org/about/) when the first transcripts were prepared.
